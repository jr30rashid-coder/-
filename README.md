# مُسيّرات 3D (Drones 3D) — مدرسة علوم الطيران المسيّر المدنية

تطبيق Android أصلي باللغة العربية (`RTL`) تعليمي مجاني ومفتوح المصدر يشرح علوم منظومات الطيران المسيّر المدنية دون اتصال بالإنترنت بعد التثبيت، وباستخدام محاكاة وبيانات افتراضية آمنة فقط.

## المزايا والوحدات التعليمية المنفّذة (المراحل 0–13)
1. **التأسيس والإعدادات والوصولية (المراحل 0–1):** واجهة عربية RTL (مع تثبيت اتجاه المخططات الهندسية والرسوم البيانية و3D بوضع LTR)، دعم ثيم النظام والألوان الديناميكية Material 3، تكبير الخط (`80%–150%`)، التباين المرتفع، تقليل الحركة، وأيقونة تكيفية مخصصة.
2. **المحتوى المحلي الآمن (المرحلة 2):** مدقق مخطط `Drones3DContentPackV1`، وفاحص أرشيفات ZIP/JSON لحجب اختراق المسارات (`../`) والمسارات المطلقة والروابط الرمزية والملفات التنفيذية وقنابل الفك مع بصمة SHA-256 والتجهيز الذري والتراجع الآمن.
3. **المدرسة التعليمية والموسوعة والمدرب (المرحلة 3 — 8 مسارات / 15 درساً):** دروس متدرجة عبر المسارات الثمانية بـ 4 مستويات (تشمل الأرصاد الجوية وكثافة الهواء وقص الرياح وفيزياء الموجات ومنطقة فرينل) مدعومة بـ 8 صور واقعية مفردة للقطع، وأمثلة حسابية محلولة، بالإضافة إلى تبويب «الموسوعة والحاسبات» القابل للبحث مع 3 حاسبات علمية دون إنترنت ومخطط التوصيل المرجعي، وتبويب «المدرب المحلي» بالمنهج السقراطي الاستنتاجي.
4. **المختبر ثلاثي الأبعاد (المرحلة 4):** عارض تفاعلي مبني بـ OpenGL ES 2.0 داخل `GLSurfaceView` يعرض الأجزاء الرئيسية منفصلة (**المحركات، البطارية، المراوح** وبقية المكونات) مع خطوط إرشاد التركيب، التدوير والانتقاء باللمس (3D Ray-Picking)، واجهة تحكم عائمة لإعادة ضبط الكاميرا وتبديل العرض السلكي والملون (`Wireframe / Shaded`)، ولوحة سفلية (`BottomSheet`) تعليمية تفصيلية لكل قطعة.
5. **محاكي الطيران التدريبي 3D والمحاكاة الفيزيائية (المراحل 5–6):** ميدان طيران خارجي ثلاثي الأبعاد بـ OpenGL ES 2.0 (منصة هبوط H، شبكة مترية، ظل ديناميكي، بوابات مسح جوي ثلاثية، 4 زوايا كاميرا تشمل «منظور FPV» بمؤشر OSD، وتحكم بالمحاور الأربعة) فوق محرك فيزياء `fixed-step (0.02 s)` حتمي بوحدات SI يشمل تأثير الأرض وتدوير الدفع مع الانعراج + 5 سيناريوهات تدريبية موجهة.
6. **اللوائح والورشة والتشخيص (المراحل 7–8):** بوابة لوائح مقيدة بالحالة (`REVIEW_REQUIRED` / `DRAFT`) وتحذير التقادم واختلاف الدول، وحاسبة توافق المكونات، ومُشخّص مبني على الأدلة يظهر «الأدلة غير كافية.» عند النقص.
7. **البرمجة المرئية المعزولة وتحليل السجلات (المراحل 9–10):** مفسر AST مقيد الأنواع والخطوات والعمق + منحنيات القياسات ومقارنة الرحلات ورفض السجلات الناقصة.
8. **التقدم المحلي والنسخ الاحتياطي (المرحلة 11):** تخزين خاص ذري في مساحة التطبيق مع تصدير واستيراد عبر SAF وبصمة SHA-256 دون أذونات تخزين أو شبكة.

## التقنية المستخدمة وإعدادات SDK الفعلية
- **اللغة والإطار:** Kotlin `2.2.10` + Jetpack Compose (`composeBom = 2024.09.00`) + Material 3 + OpenGL ES 2.0.
- **أداة البناء:** AGP `9.1.1`.
- **حزمة SDK الفعلية:** `compileSdk = 36` (`minorApiLevel = 1`)، `targetSdk = 36`، `minSdk = 24`.
- **معرّف التطبيق:** `com.aistudio.drones3d.kqvmrx`.
